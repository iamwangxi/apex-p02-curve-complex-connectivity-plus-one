# Finite computations: scope and expected results

Run `python3 -B scripts/run_checks.py` from the repository root. The runner recomputes all six JSON records, compares parsed values and exits nonzero on any failed assertion or mismatch. The programs use only Python's standard library. They print JSON rather than modifying the recorded files. Assertions must remain enabled.

## Genus-three enumerations

`genus_three.json`, generated by `verify_genus_three.py`, enumerates all 128 labelled oriented ribbon encodings for the complete four-vertex intersection graph minus a fixed edge, and all 1,024 for the complete four-vertex graph. There are 32 and 640 capped-genus-three encodings respectively; all have a graph edge whose two sides belong to the same face. Missing-edge choices are equivalent by relabelling. These are encodings, not isotopy-class classifications.

## Actual ribbon descent

`ribbon_descent.json`, generated by `verify_ribbon_descent.py`, uses seed `20261023`: 210 accepted dense ribbon inputs and four square-genus descent trees. It records 225 filling stellar steps, 71 nonfilling terminal cones and 296 visited nodes. The chosen rainbow lengths are one and two, and its `maximum_depth` is one. That record alone does not test longer rainbow cycles or a branch with several consecutive filling replacements.

The same program checks 56 bipartite ribbon parameter pairs, 14 square-genus ribbon examples, an explicit coface-adjacency failure certificate, and the first full mod-two homology cover. The cover has degree 64, genus 129, 160 curves, 384 intersections and 128 twelve-sided faces. It has no dual loop and has a rainbow dual two-cycle, so its dual systole is two. The extra examples are finite diagnostics, not additional connectivity theorems.

## Independent combinatorics and covering implementation

`combinatorics.json`, generated by `verify_combinatorics.py`, uses a separate permutation implementation. It checks 132,109 labelled dense intersection graphs on four through eight vertices and 136,187 admissible graph/threshold pairs, including 90 two-face degree-two exceptions and 50 one-face leaf exceptions.

It enumerates 40,899 labelled multigraphs with $`1\leq F\leq5`$ vertices and exactly $`F+1`$ edges, retaining loops and parallel edges. More edges reduce to this case by taking a subset. It also checks 110 bipartite parameter pairs, the integer connectivity bounds through genus 100,000, square parameters through 10,000, the changed subdivision interface in dimensions three through eight, and an independent connected 64-sheet covering graph with the same numerical invariants.

## Longer cycles and a consecutive filling branch

`long_cycles.json`, generated by `verify_long_cycles.py`, uses seed `2026102301`. It deliberately selects a length-three rainbow cycle on a five-curve genus-four system with ten intersections and four faces. One filling branch has

```math
(I,F)=(10,4)\longrightarrow(8,2)\longrightarrow(7,1)\longrightarrow I\leq6.
```

It records three filling stellar steps and four nonfilling terminal cones. `maximum_filling_depth` is two because depth starts at zero; the branch has three filling operations. The insertion/deletion functions are reused from `verify_ribbon_descent.py`, while an independent integer-dart implementation checks the resulting rotations, Euler characteristic, faces and intersection graph at each step. This is an additional stress test, not a fully independent implementation of insertion/deletion.

## Every positive intersection bound

`bounded_intersection.json`, generated by `verify_bounded_intersection.py`, checks the all-bound proof with no project imports. It covers 954 connected multigraphs, 26,281 exhaustive rank comparisons, 63,988 color-capacity optima (4,068 also checked by augmentation), 97,838 weighted graphs, 16,988 admissible even-threshold instances and 540,324 proper-color inequalities. It checks all low-face classifications, 40,899 multigraph short-cycle bounds and 499,500 genus/intersection parameter pairs.

Its surface part has 295 admissible complete ribbon models and 44 prime-degree cyclic covers, using degrees from 2 through 31. Input minimality follows from same-sign pairwise algebraic intersections. Among the 339 models, 154 have at least as many faces as colors; 11 selected cycles have repeated colors. Each selected cycle is checked against the dual cellular boundary matrix for nonzero mod-two homology, and every replacement facet strictly decreases. Fixed seeds are recorded in the JSON.

## Independent all-bound implementation

`bounded_independent.json`, generated by `verify_bounded_independent.py`, is a separate implementation with seed `202610280811`; it imports neither the preceding program nor other project modules. Its four phases are also available through `--phase numeric`, `graphs`, `matroids` or `surfaces`.

The arithmetic phase scans 3,427,973 weighted graphs and checks 465,466 admissible even-threshold instances, 11,662,696 proper-color inequalities and 1,639,039 small-face candidate vectors. It covers 999,000 ordinary parameter pairs and 10,000 large-integer pairs. The graph phase checks 3,181 connected multigraphs, 168,809 rank comparisons, 28,629 capacity optima and 3,528 augmentation comparisons, plus 40,899 exhaustive and 20,000 seeded short-cycle tests. The matroid phase compares the independent-representatives rank condition with exhaustive search in 10,000 binary-matroid instances, and checks 30,000 capacity optima against both the rank minimum and augmentation.

The surface phase constructs 1,927 admissible actual closed orientable surfaces, including 1,862 with $`d\geq2`$. It compares 26,366 color-subset ranks with actual deleted-edge components, and tests all 18,185 nonzero cycles of the selected subgraphs by cellular homology. The 2,607 embedded-cycle patterns include 778 with repeated colors, 584 with all color multiplicities even, and 185 with all signed input intersections zero. All have nonzero surface mod-two homology and strict facet descent. Three two-face cases without dual loops are included. Full rotation-system witnesses are embedded in the JSON, including a repeated-color cycle that has zero signed intersection with every input.

Both programs print one deterministic JSON object, containing no runtime or machine-specific fields, and write no files. The runner recomputes both objects and compares every parsed value with its reference, including the witnesses. Assertion ranges and seeds are retained from the reviewed programs; only documentation, output packaging and timing/file-write behavior have changed. Neither program constitutes a new independent review of this repository's wording.

## Limits of every computation

The written surface lemma justifies the nonfilling terminal cones. The programs do not compute or certify those boundary curves' isotopy classes. They do not prove arbitrary-genus homotopy statements, classify all curves, determine worldwide novelty, or constitute formal verification. The covering tower beyond its first level and the vertex-relative homotopies rely on the proofs. Expected JSON files are included so finite computations are reproducible and inspectable.
